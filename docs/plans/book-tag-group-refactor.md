# 书籍标签与分组重构计划

状态: 已实施, 已完成代码与自动化验证.

## 目标

将书架分组收敛为本地目录和标签两类. 本地目录分组反映书籍所在的目录; 标签分组根据书籍标签实时生成. 批量选择书籍时, 用户可以为这些书籍添加已有标签或创建并添加新标签.

## 已确认的行为

- 所有级别的本地目录名都加入标签. 例如目录 `/Books/ghs` 会产生 `Books` 和 `ghs` 两个标签; 根路径分隔符不作为标签.
- 路径标签按目录名作为标签身份, 不区分根目录. 不同根目录下的同名目录会合并到同一个标签, 例如 `/A/Shared` 和 `/B/Shared` 都使用 `Shared` 标签, 便于汇总筛选.
- 仅在检测到新书时, 根据其本地目录层级初始化路径标签; 后续目录扫描不自动补回已移除的路径标签.
- 批量添加标签时, 可以选择已有标签, 也可以创建新标签.
- “已读/未读”是不可删除的内置标签; 路径标签可以从单本书籍上删除, 也可以作为已有标签添加到其他书籍.
- 移除失效的“连载/完本”等分组时保留书籍已有标签. 路径标签用于简洁筛选和汇总, 不要求唯一标识完整目录路径.
- 标签分组按书架中书籍当前拥有的标签动态计算, 不作为独立的手动分组保存.
- 本地目录分组保留目录身份, 与标签分组在书架 Tab 上通过图标区分.
- 批量选择操作添加标签, 不通过改写分组位来模拟标签操作, 也不改变本地目录归属.

## 实施步骤

1. **盘点现有数据与行为**
   - 梳理书籍标签字段、标签规则、分组位、本地目录分组和阅读状态的读写路径.
   - 确认旧“连载/完本”等分组、规则及数据库记录的来源和迁移影响.
   - 为现有行为和数据迁移建立可验证的基线.

2. **定义标签来源与内置标签**
   - 将“已读/未读”纳入内置标签, 统一标签查询和展示入口.
   - 将本地目录的每一级目录名加入对应书籍的标签集合, `/Books/ghs` 对应 `Books`、`ghs`.
   - 仅在首次检测到新书时初始化其目录层级标签; 已有书籍的目录重新扫描不补回已删除标签.
   - 区分内置、目录派生和用户添加标签; “已读/未读”继续沿用当前阅读状态判定并随阅读状态更新.

3. **清理失效的状态分组**
   - 移除“连载/完本”等失效的标签分组和相关自动分组规则.
   - 增加数据库迁移, 只清理过期分组数据, 不误删书籍和仍有效的标签.

4. **重构标签分组数据与书架筛选**
   - 标签分组仅根据书架书籍当前标签实时计算, 没有书籍使用的标签不显示为书架分组.
   - 本地目录分组仍由目录关系产生; 两类分组在 Tab 上显示不同图标.
   - 清理依赖旧分组位的筛选、排序、数量统计和空分组处理.

5. **将多选操作改为批量添加标签**
   - 替换多选工具栏中的“移至分组”操作.
   - 标签选择器支持选择已有标签和创建新标签, 并将选定标签添加到所有已选书籍.
   - 批量添加不得覆盖已有标签, 不得改变本地目录关系.

6. **验证与收尾**
   - 覆盖内置标签、目录多级标签、标签实时计算、批量添加、旧数据迁移和书架 Tab 展示.
   - 使用 Windows 侧 Gradle 工具链编译并打包, 在真机验证关键流程.

## 实施结果

- `BookTags` 统一解析用户、来源、目录和已读/未读标签; 标签分组按书架实时计算, 包含原有展示标签(格式、大小、字数).
- 新增 107 -> 108 数据迁移, 删除旧手动/自动分组和规则, 仅保留全部与本地目录分组.
- 新书首次导入初始化多级目录标签; 后续扫描不会补回用户删除的路径标签.
- 书架、书籍详情和书架管理的批量操作统一为添加已有或新建标签.
- Windows 编译、Lint、Debug 打包通过; 757 项单元测试通过; Redmi K60 已安装并验证标签 Tab 与批量添加入口.
